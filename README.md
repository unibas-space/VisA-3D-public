# VisA-3D-public

This repository contains **From Zero to 3D - From 3D to a Game**, a practical workshop covering modelling in Blender, importing assets into Godot, and implementing a simple orbital simulation in C#.

Start with the [complete walkthrough](From%20Zero%20to%203D%20-%20From%203D%20to%20a%20Game/VisA-3D-Walkthrough.md). It includes the prerequisites, modelling steps, Godot setup, and simulation code. Continue with the optional [rocket-exhaust bonus](From%20Zero%20to%203D%20-%20From%203D%20to%20a%20Game/VisA-3D-Bonus-Rocket-Exhaust.md) after the core workshop.

```text
VisA-3D-public/
├── From Zero to 3D - From 3D to a Game/
│   ├── VisA-3D-Walkthrough.md            # Complete workshop walkthrough
│   ├── VisA-3D-Bonus-Rocket-Exhaust.md   # Optional exhaust effect
│   ├── assets/                          # Textures, sky, and material presets
│   ├── doc-assets/                      # Images grouped by topic; includes index
│   ├── code/                            # C# examples for Godot
│   └── tools/                           # Blender helper and numerical orbit check
├── Students-works/
│   ├── firstname-lastname/
│   │   ├── blender/                     # Models, assets, exports, and renders
│   │   └── godot/                       # Complete Godot project
│   └── ...
└── README.md
```

Create your own student folder, replacing `firstname-lastname` with your name or a nickname. Keep your work inside that folder. The existing empty example folders can be left unchanged.

## Submission rules (voluntary)

> [!WARNING]
> Your public fork and submission will be publicly visible. Using a nickname for your folder does not make your GitHub account or commit history anonymous.

Place your Blender files, Godot project, and required assets under **`Students-works/firstname-lastname/`**, using the `blender/` and `godot/` subdirectories above.

1. Click **Fork** to create your own copy of this repository.
2. Clone your fork and create a branch named **workshop-submission**.
3. Add your work to your folder, commit your changes, and push the branch to your fork.
4. On GitHub, select your submission branch and choose **Contribute → Open pull request**. Target **unibas-space/VisA-3D-public → main**. Include your name or chosen nickname and a brief description.
5. If corrections are requested, commit and push them to the same branch. The pull request updates automatically.

You can also complete the workshop locally without submitting: download and extract the repository ZIP, use the same folder layout, and omit the push and pull request.
